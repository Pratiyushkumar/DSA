# Data Structures and Algorithms (DSA)

A comprehensive collection of Data Structures and Algorithms implementations in multiple programming languages.

## 📚 Overview

This repository contains implementations of fundamental and advanced data structures and algorithms. Each implementation is carefully crafted to demonstrate best practices, clarity, and efficiency.

### Languages

- **TypeScript** (71.3%) - Primary language for implementations
- **Python** (16.9%) - Additional implementations and utilities
- **JavaScript** (11.8%) - Complementary JavaScript implementations

## 🎯 What's Included

### Data Structures
- Arrays & Linked Lists
- Stacks & Queues
- Trees (Binary, BST, AVL, etc.)
- Graphs
- Hash Tables & Hash Maps
- Heaps & Priority Queues
- Tries & Suffix Trees
- Disjoint Sets (Union-Find)

### Algorithms
- Sorting (Quick Sort, Merge Sort, Heap Sort, etc.)
- Searching (Binary Search, Linear Search)
- Graph Algorithms (BFS, DFS, Dijkstra, etc.)
- Dynamic Programming
- Greedy Algorithms
- Divide and Conquer
- Backtracking
- String Algorithms

## 🚀 Getting Started

### Prerequisites
- Node.js/npm (for TypeScript/JavaScript)
- Python 3.x (for Python implementations)
- Git

### Installation

```bash
git clone https://github.com/Pratiyushkumar/DSA.git
cd DSA
```

### Running Examples

**TypeScript:**
```bash
npx ts-node src/example.ts
```

**Python:**
```bash
python3 script.py
```

**JavaScript:**
```bash
node script.js
```
